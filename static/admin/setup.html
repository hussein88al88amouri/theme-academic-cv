Edit your website from the browser

Sign in with your repository-owner GitHub account. Once signed in, edit your biography, interests, picture, publications, projects, posts, headings, navigation, and colors. Save a draft, review it, then publish. Netlify rebuilds the website after publication.

If sign-in shows “api.netlify.com/auth Not Found”

The editor uses GitHub authorization through your existing Netlify project. This requires a one-time account setup:

  1. In GitHub, open Settings → Developer settings → OAuth Apps → New OAuth App.
  2. Set the homepage to https://hussein-el-amouri.netlify.app and callback URL to https://api.netlify.com/auth/done.
  3. In the existing Netlify project's security/access configuration, find OAuth / Authentication providers and configure GitHub using that app's client ID and client secret. Enter the secret only in Netlify's secure settings.
  4. Confirm the Netlify project is linked to hussein88al88amouri/theme-academic-cv, branch main. Deploy the latest commit.
  5. Return to the primary editor address, refresh, and choose Login with GitHub.

The login target must identify hussein-el-amouri.netlify.app. The deployed configuration places this under backend.site_domain. If a login popup is blocked, allow popups for this site. Only accounts with repository write permission can publish.

Contact settings

The public site uses a direct email link by default. No message boxes or email-service credentials are needed. An optional Netlify contact form can be enabled in Homepage & career; its form detection and notifications are configured separately in Netlify.
